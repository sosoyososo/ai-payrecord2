# iOS App Icon Design — 账本 (PayRecord)

**App:** 账本 (PayRecord) — 个人记账/财务管理 App
**Bundle ID:** com.payrecord.app
**Platform:** iOS (Capacitor)
**UI Theme:** shadcn/ui 极简现代风

## 配色方案

| Token | Color | HSL |
|-------|-------|-----|
| Primary | 🔵 Blue | hsl(210, 100%, 50%) ≈ #0080FF |
| Accent | 🟢 Emerald Green | hsl(160, 84%, 40%) ≈ #11A872 |
| Background (light) | White | hsl(0, 0%, 100%) |
| Background (dark) | Dark Navy | hsl(222.2, 84%, 4.9%) |

## Icon Design

- Style: iOS 原生极简风格
- Main color: Blue gradient (#0080FF → #0066CC)
- Element: 简洁的账本/钱包符号，白色线条或白色剪影
- Background: 白色底 + 蓝色主元素，或蓝色渐变底 + 白色图标
- Format: 1024x1024 PNG
